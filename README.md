# 🎌 Anime Toolkit

Interactive anime tier list built with Angular and Jikan API.

## ✨ Features
- Search anime by season and year
- Filter by type (TV, Movie, OVA, etc.)
- Drag & drop tier board
- Custom tiers (add/remove/reorder)
- Custom tier colors
- Dark mode

## 🛠 Tech Stack
- Angular
- Angular CDK (Drag & Drop)
- Jikan API (MyAnimeList)
- SCSS + CSS variables
